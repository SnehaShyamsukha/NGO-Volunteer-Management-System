\# NGO Volunteer Management System



A full-stack web application that helps NGOs efficiently manage volunteers, events, registrations, attendance, and volunteer activities through a centralized digital platform.



\## 🚀 Features



\### 🔐 Authentication \& Authorization

\- Secure JWT-based authentication

\- Role-based access control

\- Separate Admin and Volunteer dashboards

\- Forgot password functionality using email verification



\### 👥 Volunteer Management

\- Add, update, and manage volunteer profiles

\- View volunteer details and activity records

\- Search and filter volunteers

\- Track volunteer participation



\### 📅 Event Management

\- Create and manage NGO events

\- Volunteer event registration

\- Registration approval workflow

\- Event status management



\### ✅ Attendance Management

\- Manual attendance marking

\- 6 digit unique code based attendance system

\- Attendance history tracking



\### 📜 Certificate Generation

\- Automatic volunteer certificate generation

\- PDF certificate download functionality



\### 📊 Dashboard \& Analytics

\- Admin dashboard with insights

\- Volunteer statistics

\- Event and attendance analytics

\- Interactive charts and visualizations
